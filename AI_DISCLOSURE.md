# AI use in Mission Control (Team Pawstronauts)

**Short version:** we built Mission Control with help from an AI assistant, **Claude (by Anthropic)**.
The team decided what the game is, who plays what, how it should feel, and tested it with real players.
The AI helped write and fix code, check the maths, balance numbers, draft text and build the handbook.

> TEAM: before you submit, read this page and `data/credits.json` and change anything that is not true for
> you (for example who drew which picture). The game's Credits screen reads `data/credits.json`, so the game,
> this page and the README always say the same thing. Also check the NASA Space Apps rules on AI disclosure.

## Where it says so
- **Every script** (`.gd` and `.py`) starts with: `# AI-assisted: written with help from Claude (Anthropic)...`
- **Every screen** shows "Made with AI assistance" next to the version in the bottom-right corner.
- **Screens with the menu background** show "Background: AI-generated / AI-assisted" in the bottom-left corner.
- **Main menu > Credits & AI use** lists everything below.
- `data/countdown_data.json` has `meta.ai_note`; the README has an "AI assistance" section.

## What was AI-assisted
| Part | AI use | Notes |
|---|---|---|
| Game code (GDScript), tests, build tools | AI-assisted | Each teammate built their module with Claude using the shared prompt pack (`PROMPTS.md`); the Lead merged with Claude's help. |
| Maths (`reference_sim.py`, `SimEngine.gd`) | AI-assisted | Checked by 12 golden tests. |
| Numbers and item text (`data/`) | AI-assisted | Game-scale numbers loosely inspired by real missions, not official NASA data. |
| Commander's Handbook (PDF and in-game) | AI-assisted | Built from the game data by AI-assisted code. |
| Sound effects and music | AI-assisted | Generated by code (`tools/make_sfx.py`), no third-party audio. |
| Medal pictures | AI-assisted | Drawn by code (`tools/make_medals.py`). |
| Menu backgrounds and title art | AI-generated / AI-assisted | TEAM: confirm. |
| Cat astronaut portraits | Drawn by the team's artist | TEAM: confirm. |

## What people did
Game idea and design choices, the Commander (Keep Talking) direction, role balance, play-testing, art direction,
deciding which AI suggestions to keep, and checking the results in play.
